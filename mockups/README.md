# Mockups

Clickable HTML mockups for Vektor Desk. Open `index.html` in a browser; no build step. The spec they illustrate is [docs/design.md](../docs/design.md).

- `assets/desk.css`: Jetset Orbit tokens (from Escape Vektor) with desk density, shell, components.
- `assets/desk.js`: shell, combo boxes, tooltips, SVG charts, Symbol sheet, drill drawer, Console.
- `assets/parts.js`: KPI tile, proposal card, Preflight lights, departures board, stamped ledger.
- `assets/data.js`: synthetic sample data. No real balances, holdings or account details belong in this folder.

Screenshots are for checking work only and are not committed.
